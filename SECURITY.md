# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for a security vulnerability.

Email the maintainers listed in [CONTRIBUTING.md](CONTRIBUTING.md). If you don't get a response within seven days, email oss-community-management@datarobot.com. For questions about DataRobot products, contact support@datarobot.com.

Include the affected file or version, steps to reproduce, and the impact you see. We will confirm receipt, investigate, and tell you when a fix is released.

## Scope

This repository holds a template for running the Hermes agent as a DataRobot workload. It contains no credentials. Secrets reach a deployed workload only as environment variables from DataRobot credentials. If you find a secret in this repository or its history, report it the same way.

## More information

DataRobot's security practices are described in the [Trust Center](https://www.datarobot.com/trustcenter/).
